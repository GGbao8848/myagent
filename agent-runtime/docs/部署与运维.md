# AgentRuntime 部署与运维

## 开发环境启动

```bash
cd agent-runtime
# 1. 创建虚拟环境并安装依赖
uv venv --python 3.11 .venv
uv pip install --python .venv/Scripts/python.exe mcp pyyaml

# 2. 复制配置模板并修改（allowed_dirs / allowed_commands / 超时）
cp config.example.yaml config.yaml   # Windows: copy config.example.yaml config.yaml

# 3. 启动（默认监听 127.0.0.1:18544）
PYTHONPATH=src .venv/Scripts/python.exe -m agent_runtime
```

用官方 MCP Inspector 调试：

```bash
uvx mcp dev src/agent_runtime/server.py
```

## Windows 下启动（脱离会话，防被回收）

直接 `python -m agent_runtime` 在后台/脚本里跑可能被进程回收（exit 127，日志显示启动成功但进程随后退出）。用 PowerShell `Start-Process` 脱离启动：

```powershell
Start-Process -FilePath 'E:\br\MCP\agent-runtime\.venv\Scripts\python.exe' `
  -ArgumentList '-m','agent_runtime' `
  -WorkingDirectory 'E:\br\MCP\agent-runtime' -WindowStyle Hidden
```

## 停止 / 重启

```powershell
# 找 PID：netstat -ano | findstr 18544
taskkill /PID <pid> /F
# 再按上面的 Start-Process 重新启动
```

> **重启后注意**：调用方（BR-Agent server）缓存的 MCP 连接（streamable-http session）会失效，旧连接调用报 `Session not found`。BR-Agent 已实现缓存 TTL(120s) + 连接失效自动重连，无需手动干预；其他 MCP 客户端如无自愈逻辑需自行重连。

## 打包安装包

```powershell
powershell -File packaging/build.ps1      # PyInstaller 打包
# 产物：packaging/output/
# Inno Setup 脚本：packaging/AgentRuntime.iss
```

## 装成 Windows 服务（开机自启，推荐生产环境）

```powershell
# 需管理员权限；NSSM 管理
powershell -File packaging/install_service.ps1
# 卸载：packaging/uninstall_service.ps1
```

安装后配置文件默认读 `%PROGRAMDATA%\AgentRuntime\config.yaml`，审计日志建议指向 `C:\ProgramData\AgentRuntime\logs`。

## 验证服务正常

```bash
# 1. 端口在听
netstat -ano | findstr 18544

# 2. MCP initialize 握手（应返回 capabilities + instructions）
curl -s -X POST http://127.0.0.1:18544/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"check","version":"1.0"}}}'

# 3. 审计日志持续写入
tail -f logs/audit.log
```

## 审计日志解读

```
2026-08-13 14:20:11 [INFO] tool=local_exec success=True duration_ms=93 command=.venv\Scripts\python.exe -c "import sys; print(sys.executable)" cwd=.
2026-08-13 14:20:15 [INFO] tool=local_exec success=False duration_ms=0 command=del /q demo.py cwd=. message=拒绝执行：命令 'del' 不在白名单内（已允许：[...]）
```

- `success=False` + `message=拒绝…`：白名单/路径校验拦截（正常防护）
- `success=False` + `message=命令执行超时`：超过 `exec_timeout_seconds` 被终止
- 记录中的敏感参数已截断（200 字符）

## 常见问题

| 现象 | 处理 |
|---|---|
| 启动报端口占用 | `netstat -ano \| findstr 18544` 找到 PID 杀掉，或改 `server.port` |
| Agent 调用报 `Session not found` | 服务刚重启，调用方缓存旧连接；BR-Agent 会自动重连，等待 ≤2 分钟或重启 BR-Agent server |
| `import xxx` 报 No module named | 用 `uv pip install --python .venv\Scripts\python.exe xxx` 装到工作区 venv（勿用系统 pip） |
| 命令被「拒绝执行」 | 命令名不在白名单，或参数含白名单目录外的绝对路径——按需调整 `config.yaml` |
