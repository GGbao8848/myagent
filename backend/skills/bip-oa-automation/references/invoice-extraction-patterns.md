## 酒店水单（扫描件/图片 — 需 OCR）

### 格式特征
```
迪尚精品生活酒店
客人姓名: 龙占全,曹旭
抵店日期: 2026/05/29  离开日期: 2026/05/30
BS: 605  账号: 83412935
日期        摘要              消费
2026/05/29  [605]夜审房费OTA1  190.01
Total消费合计: 190.01
地址: 上海市浦东新区泥城镇彭平东路728号
```

### OCR 关键字段提取
- **客人姓名**: 从"客人姓名"行提取
- **抵/离日期**: 从"抵店日期"/"离开日期"行提取
- **消费金额**: 从"夜审房费"行提取数字
- **酒店名称**: 页面顶部

## 费用类型判断要点

| 发票内容特征 | FeeID | 说明 |
|-------------|-------|------|
| 住宿费、酒店 | ADT01 | 住宿费 |
| 通行费（城际高速） | ADT0305 | 其他交通 — 出发地和目的地不同城市 |
| 通行费（市内） | ADT0304 | 市内交通 — 同一城市内 |
| 代收通行费（不征税） | ADT0305 | 其他交通 — 过路费附加费 |
| **油费补贴（自驾）** | **ADM03** | **车辆使用费 — 需关联行车记录 DRV，系统自动计算补贴** |

## 自驾油费补贴

自驾出差场景下，油费不是凭发票报销，而是通过**行车记录**自动计算补贴：

```
补贴金额 = 行车里程(km) × 1.2 元/km
```

费用明细中：
- FeeID = ADM03（车辆使用费/油费补贴）
- 不需要 InvcNo（无发票）
- 必须关联 DrivingRecordNo（行车记录编号）
- 系统自动计算 ActualMileage 和 SubAmt

详见 `references/driving-record-integration.md`。

## 多文件合并规则

同一费用类型、同一时间段的多张发票可合并为一条费用明细：
- **住宿费**: 每晚一条明细（日期不同），或合并为一条（日期范围覆盖整段）
- **过路费**: 去程合并一条，回程合并一条，或全部合并为一条"过路费"
- **InvcNo**: 多张发票号用逗号分隔
- **FeeAmt**: 各发票金额之和
