# 桌面客户端说明（本地 Agent / Codex 式）

## 定位

BR-Agent 的 **C/S 本地 Agent 客户端**（类似 Codex）：**agent 核心（LLM 推理 + ReAct 循环 + 工具）在用户本机运行**，不占服务器计算资源；数据经服务器 API 存库，与 web 端完全共享一致。服务器保留 B/S 在线对话平台（ChatGPT 式）。

## 架构

```
[Electron 主进程 = 本地 Agent 引擎]
├─ auth: Keycloak PKCE 系统浏览器登录（loopback 回调 30088）+ safeStorage 加密 token
├─ api.ts: REST 代理（Bearer + 401 刷新）
├─ agent/engine.ts: LocalAgentEngine
│    └─ runAgent（手动 ReAct，复用后端 runner.ts）+ createChatModel（模型配置经服务器 active-key）
├─ agent/tool-registry.ts: 本地工具（文件/命令，工作区+技能目录限定）
├─ agent/skill-sync.ts: 公开 skill 同步到本地 + 内置 Python 本地执行
├─ agent/confirm.ts: 工具确认队列（IPC 弹窗）
└─ IPC: agent:event 流 / tool:confirm / 对话

[渲染进程 = 本地 React UI]
├─ DialogueView（复用 web 组件，事件源 IPC）
├─ 侧边栏：对话 / 技能 / MCP / 模型配置（与 web 一致）
├─ 三态安全模式切换 + ToolConfirmDialog
```

## 关键机制

- **登录**：系统浏览器 → Keycloak → 跳回客户端（loopback `http://127.0.0.1:30088/callback`）。**Keycloak 需在 client `br-agent` 白名单加该地址**。
- **模型**：登录后拉服务器 `GET /api/llm/providers/active-key` → 客户端本地 `createChatModel` 调 LLM（内网 vLLM 或外部 provider）。
- **数据**：会话/消息经服务器 API 存库（`POST /api/sessions/:id/messages` 等），与 web 端共享同一份数据。
- **skill 本地化**：客户端把服务器公开 skill 下载解压到 `%APPDATA%\@br-agent\desktop\skills\<id>\`，用**打包内置 Python**（`resources/python/python.exe`，embed 3.11 + 复用 `.venv` 依赖）本地执行 `scripts/*.py`。可读技能目录（不限定工作区）。
- **MCP 工具**：客户端经服务器执行——拉 `GET /api/mcp/tools` 注册 `mcp_*` 工具，调用 `POST /api/mcp/tools/call`（复用服务器 MCP 连接，客户端无需直连外网/内网 MCP）。
- **安全模式**（会话窗切换）：完全自动 / 危险操作确认 / 每次确认。危险工具（文件写/删/命令执行）按模式弹窗确认。

## 构建 / 打包

```bash
cd apps/desktop
npm run build:main      # tsc 编译主进程 → dist/main
npm run build:renderer  # vite 构建渲染进程 → dist/renderer
npx electron .          # 本地运行

# 打包安装包（NSIS）
npm run build:desktop   # → release/BR-Agent Setup *.exe
```

### 打包注意

- **内置 Python**：`resources/python/`（embed + 依赖）经 electron-builder `extraResources` 打进安装包
- **服务器地址**：`resources/default-settings.json` 的 `serverUrl`（打包前可改，客户端直接连预设地址）
- electron-builder 打包环境：`CSC_IDENTITY_AUTO_DISCOVERY=false`、`ELECTRON_BUILDER_BINARIES_MIRROR`（npmmirror）、7890 代理；`apps/desktop/node_modules` 需预置生产依赖（`@langchain/*`、`adm-zip` 等），electron-builder 检测到 node_modules 存在会跳过 npm install（本机定制 npm 的 allow-scripts 限制）
- electron 版本**固定精确号**（33.4.11），electron-builder 才能计算版本

## 外部服务依赖

客户端需要：能访问服务器（9004/9005/6543）、LLM 可达（内网 vLLM 或外部 provider）。skill 本地执行用内置 Python，不依赖外网。局域网客户端完全可用（内网 vLLM + 服务器数据）。
