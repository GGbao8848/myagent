# 部署指南（PM2，Windows Server）

## 一、PM2 部署

配置文件：根目录 `ecosystem.config.js`（server 用 tsx 入口，web 用 vite preview，带崩溃重启 + 日志到 `logs/`）。

```bash
# 1. 安装 PM2 + 开机自启
npm install -g pm2 pm2-windows-startup
pm2-startup install

# 2. 构建前端 + 启动
cd apps/web && npm run build        # 生成 dist（preview 服务静态产物）
cd <项目根> && pm2 start ecosystem.config.js
pm2 save                            # 保存进程列表，服务器重启后自动恢复

# 常用命令
pm2 status
pm2 logs
pm2 restart br-agent-server
pm2 restart br-agent-web
```

### 要点

- **.env 加载**：server 入口 `index.ts` 用 dotenv 加载 `.env`（生产 `ENCRYPTION_KEY`、`MAX_CONCURRENT_GENERATIONS` 必须配）
- **前端生产**：`npm run preview` 服务 build 产物，端口 9005 + `/api` 代理
- **并发上限**：`MAX_CONCURRENT_GENERATIONS`（默认 700）控制全局同时生成数，超限 503
- **Windows PM2 启动**：不能直接 `npm.cmd`（Node 解析批处理失败），配置里直接跑 tsx/vite 的 js 入口（`node_modules/tsx/dist/cli.mjs` / `node_modules/vite/bin/vite.js`）
- 部署前确保：PostgreSQL、Keycloak、vLLM/外部模型可达；数据库已 `db:push`

## 二、外部服务自启动（Windows 启动文件夹）

PostgreSQL 和 Keycloak 通过启动文件夹（`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`）的 VBS 静默启动：
- `start_postgres_hidden.vbs` → `pg_ctl -D D:\PostgreSQL\18\data start`（幂等）
- `start_keycloak_hidden.vbs` → `D:\keycloak-26.7.0\start_keycloak.bat`

前后端由 PM2 自启（pm2-startup + pm2 save）。服务器重启后整套自动恢复。

### 手动启动（排查时）

```bash
# PostgreSQL
D:\PostgreSQL\18\bin\pg_ctl.exe -D D:\PostgreSQL\18\data -l D:\PostgreSQL\18\data\pglog.txt start
# Keycloak
D:\keycloak-26.7.0\start_keycloak.bat
```

## 三、桌面客户端分发

- 打包：`cd apps/desktop && npm run build:desktop` → `apps/desktop/release/BR-Agent Setup *.exe`
- 客户端默认连服务器地址在 `apps/desktop/resources/default-settings.json`（`serverUrl`），打包前可改
- Keycloak 需给 client `br-agent` 的 **Valid redirect URIs** 添加 `http://127.0.0.1:30088/callback`（桌面客户端系统浏览器登录回调）
- 客户端本机 skill 执行用打包内置 Python，无需用户装环境
